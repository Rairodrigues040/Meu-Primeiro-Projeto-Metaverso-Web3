----------------------------------------------------------------
DESCRIÇÃO
----------------------------------------------------------------

Este projeto recria o quintal de uma casa no campo em Realidade
Virtual, desenvolvido com Unity e Meta XR SDK.

A inspiração veio da vivência com família no interior, buscando
trazer um ambiente rural autêntico e imersivo para o mundo VR.

----------------------------------------------------------------
ELEMENTOS DA CENA
----------------------------------------------------------------

- Animais espalhados pelo quintal
- Campos de flores e matos
- Árvores
- Mesa com frutas
- Casa com estilo rústico
- Plano de chão (terreno do quintal/grama)
- Skybox de ambiente externo/céu

----------------------------------------------------------------
TECNOLOGIAS UTILIZADAS
----------------------------------------------------------------

- Unity (versão compatível com Meta XR SDK)
- Meta XR SDK
- Plataforma alvo: Android (Meta Quest)
- Movimentação via teclado/mouse no PC (Unity Editor)

----------------------------------------------------------------
COMO EXECUTAR O PROJETO
----------------------------------------------------------------

1. Clone ou baixe o repositório
2. Abra o projeto no Unity Hub
3. Certifique-se de que o Meta XR SDK está instalado
   (Package Manager > My Assets)
4. Abra a cena principal em: Assets/Scenes/
5. Pressione Play no Unity Editor para explorar o ambiente
6. Movimentação no PC:
      W / Seta Cima    → Andar para frente
      S / Seta Baixo   → Andar para trás
      A / Seta Esq.    → Mover para esquerda
      D / Seta Dir.    → Mover para direita
      Mouse            → Girar câmera

----------------------------------------------------------------
ESTRUTURA DE PASTAS
----------------------------------------------------------------

Assets/
  ├── ithappy/         → Assets do pacote ithappy - Veio do Assetstore.Unity
  ├── Modelos 3D/      → Modelos 3D utilizados na cena
  ├── Oculus/          → Integração com SDK Oculus/Meta
  ├── Scenes/          → Cena principal do projeto
  ├── Settings/        → Configurações de render e XR
  ├── Skybox/          → Materiais e texturas do Skybox
  ├── Texturas/        → Texturas utilizadas nos materiais
  └── XR/              → Configurações do XR Plugin

ProjectSettings/       → Configurações do projeto Unity
Packages/              → Pacotes e dependências
